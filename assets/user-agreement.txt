二、服务说明
----------------------------------------

1. 本应用是一款基于开源 AI Agent 工作台构建的本地桌面应用，在鸿蒙
   2in1 / 平板设备上提供多会话 AI 对话、Agent 工具调用、技能与插件市场、
   图片附件等功能。本应用的主要功能包括但不限于：
   (1) 多会话对话：围绕工作区开展多轮 AI 对话，会话本地持久化并支持检索；
   (2) Agent 与工具调用：可进行文件读取、写入、编辑、搜索、删除、移动、
       复制、权限修改及命令执行等操作；
   (3) 技能与插件市场：按需扩展 Agent 能力；
   (4) 图片附件及窗口、全屏、状态栏等桌面体验。
2. 本应用本身不提供、也不内置 AI 大模型。AI 对话能力由您自行在"设置 →
   模型"中配置并接入的第三方模型服务商提供。您需自行向相应服务商申请并
   配置有效的 API Key，并自行承担由此产生的服务费用及与该服务商之间的权
   利义务。
3. 本应用不提供账号注册或登录功能。您对模型服务商的配置、API Key 的保管
   以及工作区数据的管理由您自行负责。
4. 插件市场的部分能力（如"一键安装"）可能依赖您设备上已具备的工具环境，
   属于可选能力，开发者不就该等能力作可用性承诺。
