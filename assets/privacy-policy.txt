DSH Desktop 隐私政策

【引言】

DSH Desktop（以下简称"本应用"）是一款基于开源 AI Agent
工作台构建的本地桌面应用，在鸿蒙 2in1 / 平板设备上提供多会话 AI 对话、
Agent 工具调用（文件读写、编辑、搜索、删除、移动、复制、命令执行等）、
技能与插件市场、图片附件等功能。

我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。我们
致力于维持您对我们的信任，按照权责一致、目的明确、选择同意、最少够用、
确保安全、主体参与等原则保护您的个人信息。

请在使用本应用前，仔细阅读并充分理解本隐私政策的全部内容。一旦您开始使
用本应用，即表示您已理解并同意本政策。本应用不强制注册账号、不强制登录。


一、我们如何收集和使用您的个人信息
----------------------------------------

（一）我们不主动收集的信息

本应用不提供账号注册/登录功能，不收集您的手机号码、邮箱、身份证件、精
准位置、通讯录、生物特征等个人信息；不内嵌广告；不接入第三方统计分析、
崩溃上报或用户行为追踪 SDK。

（二）为实现功能而在本地处理的信息

下列信息仅存储在您的设备本地（应用沙箱目录及本地数据库），不会被我们上
传或收集：

1. AI 会话：对话记录、会话标题、工具调用过程与结果，存储于本地数据库；
2. 模型配置：您填写的模型服务商名称、接口地址及 API Key（凭据），存储于
   应用沙箱本地配置；API Key 仅用于向您指定的模型服务商发起请求；
3. 文件操作：工作区内您选择让 Agent 读取/编辑的文件内容及文件名，存储于
   应用沙箱及您授权的目录；
4. 图片附件：您主动添加的图片及其解码信息，存储于应用沙箱本地；
5. 界面与窗口：窗口位置/尺寸、视图偏好设置，存储于本地。

（三）向您自行选择的模型服务商传输的信息

本应用本身不提供 AI 大模型能力。AI 对话由您自行在"设置 → 模型"中配置
的模型服务商（以下简称"模型服务商"）提供。当您发送消息时，为完成 AI
回复，本应用会通过加密网络连接将以下内容发送至您指定的模型服务商接口地
址：

1. 您输入的对话内容、相关上下文与历史会话；
2. 您主动添加的图片附件；
3. Agent 调用工具所产生、并用于完成任务的相关文本内容。

该等信息的接收方是您自主选择并配置的模型服务商，而非本应用开发者。模型
服务商对其接收数据的处理，适用该服务商自有的隐私政策。我们建议您在配置
前阅读对应模型服务商的隐私政策，并仅向信任的服务商提供信息。您填写的
API Key 仅保存在本地，仅用于与该服务商鉴权。

（四）命令执行与文件访问

在您主动发起相关任务时，本应用的 Agent 可调用系统自带的 sh/toybox 执行
命令，并对您授权的工作区目录进行读写。命令执行与文件访问均在您的设备本
地进行，执行结果不会被我们收集；若任务涉及向模型服务商提问，相关内容按
本条第（三）项处理。本应用不会在未经您授权的情况下批量扫描您的磁盘。

（五）插件与技能

本应用提供插件市场与运行时技能。插件的安装/启用由您主动操作，插件运行
在本应用进程内。第三方插件对信息的处理由该插件的提供方负责，请在安装前
查看其说明与权限范围。

（六）例外情形

我们可能在下列情形下处理或披露相关信息，且无需事先征得您的同意：

1. 与国家安全、国防安全直接相关的；
2. 与公共安全、公共卫生、重大公共利益直接相关的；
3. 与犯罪侦查、起诉、审判和判决执行等直接相关的；
4. 出于维护您或其他个人的生命、财产等重大合法权益但又很难得到本人同意的；
5. 您自行向社会公开的个人信息；
6. 法律法规规定的其他情形。


二、我们如何使用 Cookie 和同类技术
----------------------------------------

本应用为本地桌面应用，主要界面通过本地进程内服务同源加载。应用会在本地
使用 localStorage / 数据库等技术保存您的会话状态与界面偏好，这些数据不
跨设备、不上传。本应用不使用 Cookie 或同类技术进行跨站追踪或广告投放。


三、我们如何共享、转让、公开披露您的个人信息
----------------------------------------

（一）共享

我们不会向任何第三方出售您的个人信息。由于我们不收集并上传您的会话、凭
据与文件数据，除第一条第（三）项所述由您主动配置的模型服务商（数据接收
方为该服务商）以及您自行安装的第三方插件外，我们不会与任何第三方共享您
的个人信息。

（二）转让

我们不会将您的个人信息转让给任何公司、组织和个人，但以下情形除外：

1. 在获取您明确同意的情况下；
2. 根据适用法律法规、法律程序、诉讼或政府主管部门的强制性要求；
3. 若发生合并、收购、资产转让或类似交易，我们将确保受让方继续受本政策约
   束，或要求其重新征得您的同意。

（三）公开披露

我们仅会在获取您明确同意，或基于法律法规及主管部门强制要求的情况下，公
开披露您的个人信息。


四、我们如何存储和保护您的信息
----------------------------------------

（一）存储地点与期限

1. 您的会话、配置、凭据与文件数据均存储在您设备本地的应用沙箱目录及本地
   数据库中，我们不提供云端存储、不上传至我们的服务器；
2. 我们仅在为实现处理目的所必要的最短时间内保留数据；您可随时在应用内删
   除会话或删除相关文件；卸载本应用将删除应用沙箱内的本地数据，请提前自
   行备份。

（二）安全措施

1. 与模型服务商的通信通过 HTTPS/TLS 加密连接进行；
2. API Key 等凭据仅保存在本地，不在日志中明文输出；
3. 我们采用应用沙箱隔离、最小权限申请等措施保护您的数据。

请您理解，互联网环境并非百分之百安全，且本应用的多数数据由您本地掌控。
请妥善保管您的设备、API Key 及重要文件。


五、您的权利
----------------------------------------

按照相关法律法规及通行标准，您对自己的个人信息享有以下权利：

1. 查询、访问与复制：您可在应用内查看会话记录与配置；
2. 更正、补充：您可自行修改模型配置及文件内容；
3. 删除：您可删除会话、附件及相关文件，或通过卸载应用删除本地数据；
4. 撤回同意：您可通过关闭相应系统权限、停用/卸载插件或模型配置，撤回相
   关授权；撤回不影响撤回前基于同意的处理；
5. 注销账号：本应用无账号体系，无需注销。

如您需就上述权利提出请求，可通过本政策文末的联系方式与我们联系。


六、我们如何处理未成年人的信息
----------------------------------------

本应用主要面向开发者及具备完全民事行为能力的技术用户，不会主动收集未成
年人个人信息。若您是未成年人，请在监护人的陪同与同意下使用本应用，并妥
善保管设备与 API Key。如我们发现在未获得监护人同意的情况下收集了未成年
人的个人信息，会尽快依法删除相关信息。


七、您的系统权限
----------------------------------------

为实现功能，本应用按最小必要原则申请以下系统权限，您可在设备"设置 →
应用 → DSH Desktop"中随时关闭：

1. 网络访问（INTERNET）/ 网络状态（GET_NETWORK_INFO）：与您配置的模型
   服务商通信，安装时授予；
2. 读取剪贴板（READ_PASTEBOARD）：您主动粘贴时读取剪贴板文本/图片，运行
   时弹窗，由用户授权；
3. 读写桌面目录（READ_WRITE_DESKTOP_DIRECTORY）：读写您授权的桌面目录，
   运行时弹窗，由用户授权；
4. 读写文档目录（READ_WRITE_DOCUMENTS_DIRECTORY）：读写您授权的文档目录，
   运行时弹窗，由用户授权；
5. 读写下载目录（READ_WRITE_DOWNLOAD_DIRECTORY）：读写您授权的下载目录，
   运行时弹窗，由用户授权；
6. 文件访问持久化（FILE_ACCESS_PERSIST）：文件选择器所选目录授权持久化，
   避免重复弹窗，安装时授予；
7. 可写代码内存（kernel.ALLOW_WRITABLE_CODE_MEMORY）：内置 V8/Node 引擎
   JIT 编译以保障运行性能，不用于热更新，系统授予；
8. 后台运行（KEEP_BACKGROUND_RUNNING）：维持任务与会话运行，安装时授予。

我们仅在您使用相关功能时访问剪贴板、相关目录等；拒绝授权不影响其他不依
赖该权限的功能。


八、本政策如何更新
----------------------------------------

我们可能适时修订本政策。当政策发生重大变更时，我们会通过应用内提示或页
面公告等方式通知您，并更新文首的"更新日期"。若您在政策变更后继续使用
本应用，即表示您同意受修订后的政策约束。

重大变更包括但不限于：

1. 处理个人信息的类型、目的、方式发生重大变化；
2. 个人信息共享、转让或公开披露的对象发生重大变化；
3. 您参与个人信息处理的权利及行使方式发生重大变化；
4. 负责处理个人信息的主体、联系方式或投诉渠道发生变化。
